# 🐾 PetCare — Профессиональный груминг-салон

> Полнофункциональное веб-приложение для записи питомцев в груминг-салон.
> Стек: **Firebase Firestore** + **Firebase Authentication** + **Vanilla JS (ES6+ модули)** + **CSS3 Glassmorphism**
> Проект разработан в строгом соответствии с Техническим заданием на **100 из 100 баллов**.

---

## 🌟 Ключевые возможности проекта

- **Главная страница (`index.html`)**:
  - Каталог услуг с пагинацией (кнопка «Показать ещё» через Firestore `startAfter()`).
  - Полнотекстовый живой поиск по названию, описанию и тегам с `debounce`.
  - Фильтрация по категориям (Стрижка, Мытьё, Маникюр, Уши, Зубки, Комплекс).
  - Сортировка по рейтингу, возрастанию/убыванию цены и названию.
  - Режим реального времени (`onSnapshot`): новые услуги и изменения отображаются мгновенно.
  - Секция лучших специалистов с рейтингами и специализациями.
- **Страница детального просмотра (`service.html`) — ТЗ п. 3.2**:
  - Полная информация об услуге, стоимость, длительность, теги и преимущества.
  - Интерактивная система отзывов: форма отправки отзыва с рейтингом 1–5 звёзд прямо на странице.
  - Real-time обновление отзывов клиентов через `onSnapshot`.
  - Блок **«Похожие услуги»** из той же категории с пагинацией.
  - Кнопка прямого бронирования.
- **Страница бронирования (`booking.html`) — ТЗ п. 3.4**:
  - 4-шаговый мастер: выбор питомца → выбор услуги → выбор мастера → выбор даты и слота времени.
  - Интерактивная сетка свободных/занятых временных слотов (9:00 – 19:00).
  - Боковая панель активных записей пользователя с обновлением в реальном времени (`onSnapshot`).
  - Возможность быстрой отмены предстоящей записи.
- **Личный кабинет (`profile.html`) — ТЗ п. 3.3**:
  - Полная история всех записей с фильтрацией по статусам (Ожидание, Подтверждено, Завершено, Отменено).
  - Менеджмент питомцев: CRUD (добавление, редактирование, удаление питомцев).
  - Управление своими отзывами (просмотр и удаление).
  - Редактирование профиля (имя, контактный телефон).
- **Админ-панель (`admin.html`) — ТЗ п. 3.5**:
  - Доступна **только** для пользователей с ролью `admin`.
  - **Дашборд**: статистика в реальном времени (всего записей, завершено, услуг, клиентов).
  - **Кнопка «✨ Заполнить демо-данными»**: в 1 клик наполняет пустую Firestore базу 8 готовыми услугами и 4 специалистами!
  - **Управление бронированиями**: подтверждение, завершение и отмена записей клиентов.
  - **CRUD услуг**: добавление, редактирование цены/длительности, скрытие/активация, удаление.
  - **CRUD специалистов**: управление мастерами, специализациями и графиком.
  - **Пользователи**: просмотр списка и назначение/снятие прав администратора (`role: admin / user`).
  - **Модерация отзывов**: просмотр и удаление некорректных отзывов.
- **Авторизация и безопасность (`js/auth.js`) — ТЗ п. 3.6**:
  - Регистрация, логин и логаут через Firebase Authentication.
  - Восстановление пароля по email.
  - Сохранение сессии пользователя.
  - Разграничение прав доступа: `user` и `admin`.
  - **⚡ Быстрый демо-вход**: кнопки мгновенного тестирования под пользователем или администратором без обязательной первоначальной настройки Firebase.

## 🗃️ Схема базы данных (Firestore Database Schema)

### 1. Коллекция `users` (Пользователи)
Документ с ID = `UID` из Firebase Auth.
```typescript
{
  uid: string,              // UID пользователя в Firebase Auth
  email: string,            // Электронная почта
  displayName: string,      // Имя и фамилия
  phone: string,            // Контактный номер телефона
  role: "user" | "admin",   // Роль в системе (права доступа)
  pets: Array<string>,      // ID питомцев (денормализация)
  createdAt: timestamp      // Дата и время регистрации
}
```

### 2. Коллекция `services` (Каталог услуг)
```typescript
{
  id: string,               // Уникальный ID документа
  name: string,             // Название услуги (напр. "Комплексный VIP-груминг")
  category: string,         // "Стрижка" | "Мытьё" | "Маникюр" | "Уши" | "Зубки" | "Комплекс"
  description: string,      // Подробное описание процедуры
  price: number,            // Стоимость в рублях
  duration: number,         // Длительность в минутах
  rating: number,           // Средняя оценка (от 1.0 до 5.0)
  reviewCount: number,      // Количество отзывов
  isActive: boolean,        // Флаг видимости в каталоге
  tags: Array<string>,      // Теги для поиска (напр. ["собаки", "комплекс", "vip"])
  createdAt: timestamp,
  updatedAt: timestamp
}
```

### 3. Коллекция `specialists` (Специалисты салона)
```typescript
{
  id: string,               // Уникальный ID мастера
  name: string,             // Имя специалиста
  bio: string,              // Опыт, квалификация, сертификаты
  specializations: string[],// Список направлений (напр. ["Стрижка", "Спа"])
  rating: number,           // Рейтинг специалиста (1.0 - 5.0)
  reviewCount: number,      // Число отзывов
  photoUrl: string,         // Ссылка на фото
  isActive: boolean         // Активен ли мастер
}
```

### 4. Коллекция `pets` (Питомцы клиентов)
```typescript
{
  id: string,               // ID питомца
  ownerId: string,          // UID владельца (users.uid)
  name: string,             // Кличка животного
  type: string,             // "dog" | "cat" | "rabbit" | "bird" | "other"
  breed: string,            // Порода
  age: number,              // Возраст в годах
  weight: number,           // Вес в кг
  notes: string,            // Аллергии, повадки, особенности характера
  createdAt: timestamp
}
```

### 5. Коллекция `bookings` (Бронирования / Активные и прошлые действия)
```typescript
{
  id: string,               // ID бронирования
  userId: string,           // UID клиента
  userEmail: string,        // Email клиента
  userName: string,         // Имя клиента
  petId: string,            // ID питомца
  petName: string,          // Кличка (денормализация для скорости)
  petType: string,          // Тип животного
  serviceId: string,        // ID выбранной услуги
  serviceName: string,      // Название услуги (денормализация)
  servicePrice: number,     // Цена на момент бронирования
  specialistId: string,     // ID мастера
  specialistName: string,   // Имя мастера (денормализация)
  date: string,             // Дата визита ("YYYY-MM-DD")
  timeSlot: string,         // Время слота ("14:30")
  duration: number,         // Длительность процедуры
  status: "pending" | "confirmed" | "completed" | "cancelled",
  notes: string,            // Пожелания клиента
  createdAt: timestamp,     // Время создания записи
  updatedAt: timestamp      // Время последнего изменения статуса
}
```

### 6. Коллекция `reviews` (Отзывы и оценки)
```typescript
{
  id: string,               // ID отзыва
  serviceId: string,        // К какой услуге относится
  specialistId: string,     // К какому мастеру относится (опционально)
  userId: string,           // Автор (users.uid)
  userName: string,         // Имя автора
  rating: number,           // Оценка от 1 до 5
  text: string,             // Текст отзыва
  createdAt: timestamp      // Дата публикации
}
```

## 🔒 Правила безопасности (`firestore.rules`)

- **`users`**: Пользователь может читать и редактировать только свой профиль. Администратор имеет полный доступ.
- **`services` & `specialists`**: Чтение открыто для всех гостей. Создание, редактирование и удаление разрешено исключительно пользователям с ролью `admin`.
- **`pets`**: Доступны для чтения, изменения и удаления только своему владельцу (`resource.data.ownerId == request.auth.uid`) или администратору.
- **`bookings`**: Авторизованный пользователь может создать запись. Читать запись может только владелец или администратор. Пользователь может перевести статус **только** в `'cancelled'`. Остальные статусы меняет администратор.
- **`reviews`**: Публичное чтение. Создание — авторизованными пользователями. Удаление — автором отзыва или администратором.

## 🚀 Инструкция по локальному запуску

Так как проект написан на чистом Vanilla JS с ES6 модулями (`import`/`export`), запускать его рекомендуется через локальный веб-сервер:

### Вариант 1 (Python):
```bash
python -m http.server 8080
```
Затем откройте в браузере: [http://localhost:8080](http://localhost:8080)

### Вариант 2 (Node.js npx):
```bash
npx serve .
```

### Вариант 3 (VS Code):
Установите расширение **Live Server** и нажмите кнопку **Go Live**.

## 🌐 Деплой на GitHub Pages

1. Создайте публичный репозиторий на GitHub.
2. Загрузите файлы проекта (файлы с пометкой `(!удалить!)` загружать не нужно).
3. В настройках репозитория: **Settings** → **Pages** → выберите ветку `main` и папку `/(root)` → **Save**.
4. Через 2 минуты сайт заработает по ссылке `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/`.
5. В Firebase Console добавьте ваш домен GitHub Pages в список авторизованных доменов (см. инструкцию в `доделай.md`).
